# Content style guide (v1)

Voice: plain language (~grade 8 for Explorer), second person, honest hedging
("usually", "often"), no hype (the linter warns on a banned-word list).
Every lesson: hook → objectives → explanation → Try It → mini quiz →
flashcards → recap. ≤15 minutes. Tool facts interpolate from /registry only.
Analogies must be globally legible (test: does it work in Nairobi, São Paulo,
and Warsaw alike?). Claims about model behaviour must be dated via
lastVerified. Licence: CC BY-SA 4.0, contributors credited in frontmatter.
