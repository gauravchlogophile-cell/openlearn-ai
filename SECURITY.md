# Security Policy

- Report vulnerabilities to security@ (to be configured) or via GitHub
  private vulnerability reporting.
- **Safe harbour:** good-faith research within scope will never be met with
  legal threats. Please avoid accessing other users' data; use a test account.
- Severity SLAs: critical 48h · high 7d · medium next sprint · low backlog.
- Scope and full policy: docs/governance/security-policy.md (Phase 8 spec).
